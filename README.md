# SQL Power Hour

SQL Power Hour is a hands-on SQL practice initiative designed to help developers strengthen their SQL skills through practical, progressively challenging exercises.

The repository contains topic-based questions covering SQL fundamentals and more advanced concepts, using a relational database built around realistic business data.

## Getting Started

Ready to practice? **[Read about the exercise here](https://sql-training-lab-docs.vercel.app/introducing-technova.html)** and **[Get started here](https://sql-training-lab-docs.vercel.app/setup.html)** to set up your environment and explore the exercises.
